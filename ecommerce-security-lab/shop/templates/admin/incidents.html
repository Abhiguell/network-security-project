Response playbook

Spyware / data exposure
  • Revoke the exposed API key
  • Notify affected customers (UU PDP)
  • Force password resets + enable MFA
Ransomware
  • Isolate the server from the network
  • Do not pay; identify the strain
  • Restore from offline backups, then patch
Trojan / C2
  • Block the C2 domain/IP at the firewall
  • Kill the process, remove the app
  • Re-image the device, rotate credentials
