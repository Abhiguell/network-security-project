Simulates a fake "FreeVoucherGenerator.exe" on a store POS terminal. Its hidden routine sends periodic beacons to a "C2 server" (the store's simulation API), so you can watch them live and in Wireshark. No persistence and no remote access are implemented.

What happened

  • A user installed a "free voucher" app that secretly contained a trojan.
  • It beaconed to a command-and-control server at a fixed interval and uploaded (fake) system info.
  • The store's monitoring flagged a Suspicious Application and C2 Beaconing (low timing jitter).

Real-world consequences

  • Attackers can later push other malware (ransomware, card skimmers on POS).
  • Stolen credentials allow access to the store admin panel.
  • The infected device becomes part of a botnet.

Defences

  • Application allow-listing; block unsigned downloads.
  • Egress firewall + DNS filtering to block C2 domains.
  • IDS / beacon detection on network traffic (Wireshark: http.request.uri contains "trojan").
  • User awareness: "free voucher" offers are classic lures.
